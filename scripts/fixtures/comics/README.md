# Comic reader fixtures

Generated for BOTUI from three original solid-color PNG pages (red, green, blue), using rars 0.12.4 `Builder` with `write` enabled only in a separate fixture generator. No third-party book content. RAR4 uses `ArchiveVersion::Rar29`; RAR5 uses `ArchiveVersion::Rar50`. Each has independent and solid variants. All entries are compressed, inserted in order `pages/10.png`, `pages/2 [b].png`, `pages/1.png`; reading order must be 1, 2, 10. PNGs are generated by `png(rgb, level=0)` in `scripts/smoke-comics.py`.

The production dependency disables all optional rars features; it does not include this writer. `smoke-comics.py` also creates a deflated CBZ and a stored RAR4 itself, and intercepts external unpacker commands.
