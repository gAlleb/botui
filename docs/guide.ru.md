# Руководство BOTUI

[README](../README.ru.md)

## Первый запуск

```sh
./dist/botui                                       # выбрать источник
./dist/botui --library "$HOME/Books"               # запомнить папку библиотеки
./dist/botui --local                               # вернуться в неё
./dist/botui "./examples/first-light.fb2"          # открыть файл напрямую
./dist/botui --resume                             # продолжить последнюю незавершённую локальную книгу
./dist/botui --server https://books.example.org    # корень установки BookOrbit
./dist/botui --opds https://books.example.org/opds
./dist/botui --config-path                         # создать конфиг и вывести его путь
```

При запуске выделена локальная библиотека. **Enter** открывает её. На стартовом экране перемещайте выделение, чтобы увидеть описание выбранного источника и подсказки. **B** открывает BookOrbit, **L** — локальную папку, **P** — OPDS, **D** — офлайн-книги BookOrbit, **O** — загрузки OPDS.

Выбранный пункт также открывается клавишей Enter или щелчком.

Щёлкните по обложке **в карточке книги** или нажмите **C**, чтобы открыть её в системном просмотрщике. На полке щелчок по-прежнему открывает карточку. В локальном EPUB или FB2 клавиша **C** открывает встроенную обложку.

Если у книги или каталога нет картинки, BOTUI рисует [переплёт](images/generated-jacket.png) с названием и именем автора. В PDF и DjVu клавиша **C** показывает первую страницу. BOTUI использует системную ассоциацию изображений через `xdg-open`.

**F2** открывает настройки: Appearance, Reader, Library, BookOrbit, Keys, About и Legal. **?** или **F1** сразу открывает справку для текущего экрана. Внизу есть кликабельные подсказки.

**Q** в книге возвращает на полку, ещё раз **Q** — к выбору источника; на стартовом экране **Q** завершает BOTUI. **Esc** в каталоге возвращает на один уровень. При запуске с путём к отдельному файлу **Q** закрывает этот файл и завершает команду.

В справке **?** клавиши **[ / ]** переключают разделы, а **/** ищет по клавише или описанию.

### Локальная библиотека

**Local library** открывает сохранённую папку, затем пробует `~/Books` и текущий каталог. Через **P Folder…** можно вставить путь. Кнопка **R Set library here** запоминает текущую папку как корень.

**/** открывает окно поиска по центру полки, ищет по всей библиотеке и показывает результаты уже при вводе первой буквы. Можно пропускать буквы и диакритику: `желз амб` находит Желязны и Амбер, `kukai` — Kūkai.

Сначала доступны имена файлов и подпапок; пока вы печатаете, добавляются названия, авторы и серии из EPUB/FB2. **↑/↓** выбирают книгу, **Enter** открывает её, **Esc** возвращает на полку.

**2** показывает историю чтения с процентами, **3** — книги по дате создания файла, а при её отсутствии по дате изменения.

Слева расположены дерево папок, «Сейчас читаю» и «Недавно добавленные». Щелчок по имени папки показывает её книги справа, по стрелке — раскрывает или сворачивает ветку. **F6** переключает фокус, **← / →** сворачивают и раскрывают, **Enter** открывает папку. Границу можно потянуть мышью.

В небольшом окне остаются вкладки с номерами. [Локальная библиотека в Kitty](images/local-library.png).

## Полка BookOrbit

Выберите **Connect to BookOrbit** и войдите. На дашборде доступны продолжение чтения, последние поступления и рекомендации. Когда сервер возвращает соответствующие виджеты, появятся также серия дней чтения, годовая цель, задание месяца и Reading DNA.

Щелчок по обложке открывает выбор файла издания. Нажмите **0**, чтобы вернуться на дашборд и обновить данные.

| Клавиша | Раздел | Клавиша | Раздел |
| --- | --- | --- | --- |
| 0 | Dashboard — главная | 4 | Libraries — библиотеки |
| 1 | All books — все книги | 5 | Collections — коллекции |
| 2 | Currently reading — читаю сейчас | 6 | Authors — авторы |
| 3 | Recently added — последние поступления | 7 | Series — серии |

Рядом с **Authors** и **Series** указано полное количество авторов и серий, доступных аккаунту. Внутри каждого раздела видно число книг у автора или в серии. Список томов учитывает порядок серии на сервере. **/** открывает по центру полки окно с результатами поиска.

Список обновляется при вводе; **Esc** или щелчок за пределами окна закрывает поиск. В разделах **Authors** и **Series** поиск идёт по открытому справочнику. На дашборде и книжных полках он ищет по названию, автору и серии во всём доступном каталоге BookOrbit.

Например, `желз` находит Желязны, а `znak edin` — «Знак Единорога». Список пополняется, пока BOTUI получает метаданные с сервера. Выберите строку стрелками **↑/↓** и нажмите **Enter** или щёлкните по результату. **Esc** из карточки возвращает к тому же запросу и выбранной строке.

**V** переключает сетку и список. **Tab / Shift+Tab** проходят по разделам в том же порядке, что и цифры. Книги листаются стрелками, колесом, Page Up / Page Down. Следующие записи загружаются автоматически. Enter или щелчок открывают выбранное, **Esc** возвращает назад.

### Офлайн-чтение и синхронизация

При первом нажатии **Read** BOTUI скачивает издание BookOrbit и сохраняет его на устройстве. При повторном открытии с карточки читалка берёт файл с диска, а позицию и текстовые закладки получает из аккаунта. **D Save offline** позволяет скачать книгу заранее или проверить обновление.

Если BookOrbit сообщил об изменении издания, читалка проверяет версию файла на сервере.

Без сети откройте **BookOrbit offline downloads** на стартовом экране. Если вы закрыли EPUB онлайн на пятой главе и дошли офлайн до седьмой, при закрытии читалка запомнит седьмую главу.

При действующем подключении к аккаунту или настроенном пароле (включая команду для его получения) BOTUI сам повторяет синхронизацию, пока программа запущена. Место сохраняется и после перезапуска. Если вы вводите пароль вручную, достаточно снова войти в аккаунт.

При расхождении с другим устройством BOTUI сообщает об этом и сохраняет офлайн-позицию. Офлайн-закладки хранятся локально. Для книг из каталогов OPDS есть отдельная полка **OPDS downloads** с локальным прогрессом.

На широком экране дерево навигации имеет собственную рамку. Щёлкните **Libraries** или **Collections**, чтобы свернуть группу, либо нажмите **F6** и используйте **↑/↓** и **←/→**. Клавиши **4 / 5** открывают весь соответствующий раздел; свёрнутые группы запоминаются.

Карточка до открытия файла показывает автора, серию, аннотацию, издателя, год, язык, ISBN и ваш прогресс, если сервер их вернул. **R** читает выбранное издание, **D** сохраняет его офлайн, **I** раскрывает аннотацию.

**H Put on hold** убирает книгу из активного чтения и сохраняет позицию; **H Resume reading** возвращает её. **X Reset reading state** с отдельным подтверждением обнуляет все издания этой книги в вашем BookOrbit и переводит её в Unread. Закладки, заметки и файлы сохраняются.

Читалка отправляет 100% при достижении конца; статус назначается правилами BookOrbit. Проверить доступность адресов закладок по изданиям без изменения позиции можно командой `./dist/botui --check-bookmarks "Название"`.

Так выглядят [карточка книги до чтения](images/book-details.png) и [навигация со свёрнутыми библиотеками](images/navigation-folded.png).

**L Reading log** показывает даты, устройства, длительность и прогресс сеансов, которые зарегистрировал BookOrbit. **B Related books** открывает книги автора или серии. Таймер **S** отдельно считает время в BOTUI на этом устройстве.

### Каталоги OPDS

**OPDS** принимает OPDS 1 (Atom) и OPDS 2 (JSON). Поддерживаются навигация, группы, фасеты, обложки, выбор издания, прямые загрузки, поиск по объявленному шаблону и OpenSearch. Каталоги с HTTP Basic используйте через HTTPS.

Книги, для которых доступны только выдача или DRM, отображаются без кнопки прямой загрузки. Позиции и заметки хранятся на устройстве.

## Чтение

[Разворот и панель независимой настройки ширины страницы и расстояния между колонками](images/reader-layout.png)

| EPUB и FB2 | Управление |
| --- | --- |
| Перелистнуть | Стрелки влево / вправо, Page Up / Page Down, колесо |
| Страница / разворот / прокрутка | **1 / 2 / 3**; в прокрутке ↑/↓ двигают на строку, колесо — на несколько, PgUp/PgDn — на экран |
| Меню | **M**, Esc или щелчок по странице |
| Настроить разворот с предпросмотром | **W**, затем **− / +** у строки Page width или Column gap |
| Настроить прямо во время чтения | **[** шире страница, **]** уже. **{** меньше промежуток, **}** больше |
| Дзен / обычный режим с оглавлением | **Z**. В обычном режиме **Tab** меняет фокус |
| Оглавление / поиск / ссылки и иллюстрации | **O / клавиша «/» / I** |
| Тема / непрозрачный фон / рамки | **T / F / U** |
| Поставить или снять закладку / открыть закладки | **B / G** |
| Записать заметку / открыть заметки / экспортировать Markdown | **N / A / E** |
| Вернуться после перехода / повторить переход | **, / .** |
| Статистика книги / закрыть книгу | **S / Q** |

Ширина страницы и промежуток задаются в ячейках терминала. Свободное место распределяется по краям разворота. Когда окно становится слишком узким для двух колонок, остаётся одна страница. При изменении ширины или расстояния читалка сохраняет позицию в тексте.

В EPUB и FB2 с печатными переносами она умеет соединять разорванные строки и слова. Для книг, где исходные переносы важны, укажите `preserve_printed_lines = true`.

В EPUB и FB2 щёлкните подчёркнутую ссылку или нажмите **F6**: если ссылок на экране несколько, появится выбор. Из примечания или словаря в конце книги **Esc** или кнопка **Back** возвращает к тому месту, с которого вы ушли.

**Enter · Read here** позволяет остаться в новом месте книги и продолжить оттуда. Вынесенные за основной текст сноски открываются поверх страницы. **I** по-прежнему показывает ссылки и иллюстрации всей книги.

### PDF и DjVu

Чтобы читать **PDF или DjVu**, нажмите **Enter** или щёлкните по изданию. **1 / 2 / 3** — страница, разворот и непрерывная прокрутка. При **100%** в прокрутке лист занимает ширину области чтения.

Нажмите **−** один раз для **90%**, ещё раз для **80%**; **+** увеличивает ширину, **0** возвращает подгонку. **W** открывает те же настройки для мыши; масштаб сохраняется при закрытии книги. **Z** скрывает оглавление и нижнюю строку.

**P** или **Ctrl+G** открывает небольшое окно перехода по номеру поверх страницы. **/** ищет по текстовому слою; **F3 / F4 / F5** — следующее совпадение, предыдущее и список результатов. **B / G** — закладки; **I / A / E** — заметки и экспорт.

**R / Shift+R** поворачивают скан вправо или влево, **V** переключает оригинал → инверсию → **Match background**. В этом режиме бумага и поля одного цвета: при непрозрачном фоне — цвета темы BOTUI, при прозрачном — цвета фона терминала.

В Kitty клавиша **F** переключает заливку: если выключить её в полупрозрачном окне, обои видны и на полях, и сквозь бумагу. Для темы Terminal учитывается и явно заданный непрозрачный фон. Чернила подбираются по контрасту, насыщенные цвета иллюстраций сохраняются.

Настройки сохраняются для этого издания, позиция записывается во время чтения. Локально сохраняется место внутри листа, в BookOrbit — номер страницы. Для поиска в скане без текстового слоя нужен OCR; встроенного OCR нет. [PDF в Kitty](images/pdf-scroll.png).

Встроенные растровые иллюстрации EPUB/FB2 видны в потоке текста; **I** открывает отдельный просмотрщик. Таблицы адаптируются к ширине экрана. Изображения можно отключить в **F2 → Reader → Illustrations**.

**S** показывает время по книге, а **F2 → Library → Reading statistics** — локальные итоги по устройству.

Во всех четырёх форматах **F3 / F4** переходят к следующему / предыдущему результату, **F5** возвращает список. EPUB/FB2 подсвечивают найденную фразу. В сканах показаны номера листов и фрагменты текста; **, / .** возвращают по истории переходов.

В списке закладок **G** выберите запись и нажмите **Delete** или щёлкните **[×]** на её строке, затем подтвердите удаление.

## Настройки

Команда `./dist/botui --config-path` выводит точный путь. По умолчанию это `~/.config/botui/config.toml`. В одном файле находятся локальная папка, оформление, привязки клавиш и подключение к BookOrbit. Интерфейс по умолчанию английский. См. [пример со всеми настройками](../config.example.toml).

При первом запуске интерфейс использует **Catppuccin Mocha**. Существующий выбор темы сохраняется. **F2 → Reader → First-line indent** задаёт красную строку: 0–8 ячеек, 0 отключает её. Ширину навигации и оглавления можно независимо менять за правый край мышью или через настройки.

**F2 → Library → Download limit** задаёт предел на одно издание BookOrbit или OPDS: по умолчанию **4096 МиБ**, **0** снимает ограничение. Книга скачивается частями на диск. [Экран справки](images/help.png).

**F2 → Appearance** меняет палитру интерфейса независимо от бумаги книги (**T**). Terminal использует стандартный фон, текст и цвета ANSI; изменения настроек самого терминала видны без перезапуска. В непрозрачном режиме цвет бумаги берётся из ответа терминала (OSC 11).

Если ответ недоступен, используется ANSI black или заданный вами `opaque_color`. Ни pywal, ни matugen не требуются. Встроены Gruvbox, Catppuccin, Nord, Dracula, Tokyo Night, Solarized, One Dark, Kanagawa, Rosé Pine и Everforest.

Выбранная именная палитра сохраняется; прозрачность показывает фон окна. Здесь же настраиваются углы рамок и обложек: Rounded, Square или None.

[Настройки интерфейса](images/settings.png)

```toml
library_root = "/путь/к/книгам"
interface_theme = "catppuccin-mocha"
theme = "terminal"
reading_layout = "auto"    # auto, single, spread, scroll
borders = "rounded"        # rounded, square или none
opaque_background = false
page_width = 78
column_gap = 4
paragraph_indent = 0
max_download_mib = 4096
scan_zoom = 100

[bookorbit]
server = "https://books.example.org"
username = "reader"
password_command = ["pass", "show", "bookorbit"]
# password = "ваш пароль"

[keys]
n = "next"
p = "previous"
```

Для менеджера паролей используйте `password_command`. Массив запускает команду с указанными аргументами. Строка выполняется через `sh -c`. Команда должна успешно завершиться и выдать пароль первой строкой. Для хранения открытым текстом есть поле `password`.

Если оба поля пусты, пароль вводится при входе. Приоритет имеет введённый пароль, затем команда, затем пароль из конфига. Сохранённые данные привязаны к адресу сервера и имени пользователя. Токены находятся в памяти, обычный выход завершает серверную сессию.

Читалка создаёт файл с правами `0600`. При обновлении она переносит старые настройки, подключение и привязки из JSON в TOML и сохраняет оригиналы в `$XDG_STATE_HOME/botui/config-backup`. Изменения через интерфейс сохраняют комментарии и посторонние ключи.

Доступны палитра терминала и схемы чтения BookOrbit. **F** задаёт фон ячеек. Прозрачность всего окна зависит от терминала и композитора.

| Данные | Путь по умолчанию |
| --- | --- |
| Конфигурация | `~/.config/botui/config.toml` |
| Позиции, локальные закладки, заметки и история | `~/.local/state/botui/` |
| Скачанные книги и экспорт заметок | `~/.local/share/botui/downloads/`, `~/.local/share/botui/exports/` |

Каталоги можно переопределить переменными XDG. Локальные позиции привязаны к содержимому файла. Переименование и перенос книги сохраняют место чтения.
